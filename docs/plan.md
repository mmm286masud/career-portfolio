# IS218 Career Portfolio — Project Plan

## Problem and Purpose
Technical recruiters and hiring managers need a quick way to understand a candidate's technical skills, projects and professional direction.

This project will research AI-related career opportunities and plan a professional portfolio that presents relevant evidence clearly.

## Target Audience
Technical recruiters and hiring managers.

## Career Directions
Primary: AI Software Engineering.
Alternative: Forward Deployed Engineering.

## Employer Research
- OpenAI — Forward Deployed Engineer
- Gamma — AI Engineer
- Optum — Associate AI/ML Engineer (Healthcare)

Original employer descriptions, qualifications, research dates and comparisons will be documented separately in docs/research.md.

## Portfolio Design Comparison
Option A: Clean & Professional — light background, readable typography, simple navigation and organized project cards.

Option B: Modern Developer Portfolio — dark background, technical visuals, subtle animations and highlighted projects.

Selected: Clean & Professional.

Reason: Recruiters should be able to understand my background and find evidence of my technical skills quickly.

## Planned Portfolio Sections
- Home
- About
- Projects
- Skills
- Contact

## Five User Stories and Acceptance Criteria
1. As a recruiter, I want to read a short introduction so I can understand the candidate's career direction. Acceptance: The homepage clearly communicates the professional goal.
2. As a hiring manager, I want to explore projects so I can evaluate technical ability. Acceptance: Featured projects include descriptions, technologies and repository links.
3. As a recruiter, I want to review technical skills so I can compare them with job requirements. Acceptance: Skills are grouped into understandable categories.
4. As a hiring manager, I want to review education and experience so I can understand the candidate's background. Acceptance: The About section presents relevant information accurately.
5. As a recruiter, I want to find contact information so I can reach the candidate. Acceptance: Appropriate professional contact links work correctly.
