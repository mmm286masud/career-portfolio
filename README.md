# IS218 Career Portfolio Research

## Project Overview
This repository contains my career research and portfolio planning for IS218.

My primary career interest is AI Software Engineering. I am also exploring Forward Deployed Engineering as an alternative career direction.

The purpose of this project is to research employer expectations and plan a professional portfolio that communicates my technical skills and projects to potential employers.
